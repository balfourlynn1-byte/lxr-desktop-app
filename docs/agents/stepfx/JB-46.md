# JB-46 — Per-voice dub sends and step throws

**Status:** Design/implementation task open. **Dependencies:** JB-43 key events, JB-44 toggle, JB-45 bounded delay implementation. **Review:** JB-21/JB-23/JB-28.

## Desired behaviour
- Performance Step FX page: each step key toggles its associated FX selection ON/OFF. Physical step 1 = all FX off; do not mistake zero-based slot 0 for physical step 0.
- Dub **throw** sends a selected voice to the existing delay bus for an accented hit or short rhythmic window. Releasing/turning off the send must not erase echoes.
- Per-voice mask defaults to **exclude kick** (voice 0); preserve native sequencer key behaviour outside Step FX page.
- Keep delay feedback and wet return audible after send-off, but stop all new send input.
- Define momentary vs latched throw explicitly in UI and tests; don't conflate send enable with delay-tail clearing.

## Implementation checkpoint (2026-11-08)
- Six per-voice native mixer taps and 64-sample fades implemented; default OFF and kick excluded.
- **Important limitation:** existing `FxBus_process` delay blends the send's dry signal at partial dry/wet. To avoid dry duplication, the taps are now gated to `FX_DELAY` with `fxBus.dryWet>=0.999f`. The user must explicitly select delay and 100% wet; no silent FX takeover.
- This is an interim compatibility guard, **not** a fully independent auxiliary send. FX routing and user global dry/wet remain unchanged.
- Static six-voice routing regression added to host DSP gate; actual audible tail and 2–4 voice hardware tests remain OPEN.
