## Source findings
- `Core/Src/Soundengine/DSPAudio/FX/Delay.c` already implements native delay, feedback, tone filtering and ping-pong processing. Do **not** allocate a duplicate large audio delay buffer.
- `Core/Src/Soundengine/FxBus.c` owns the global FX slot and processes the FX bus; delay is selected by `FX_DELAY`. The existing FX buffer is shared with other global FX, so concurrent dub delay + other FX is **not available without architectural changes**.
- `Core/Src/Soundengine/DSPAudio/mixer.c` mixes voice buffers into `fxBusData` and invokes `FxBus_process`. This is the safe insertion point for bounded per-voice *send* taps, not a second delay instance.
- `Core/Src/Soundengine/StepFX.c` is a MIDI retrigger scheduler; no audio delay or send routing exists there.
- Clock source available through `seq_getBpm()` and external sync; use integer bounded subdivisions and clamp time to existing FX buffer limits.
