# JB-45 — Dub delay research and bounded implementation

**Status:** Research completed; implementation pending separate safe integration. **Priority:** P1, must not block No Clip. **Review:** JB-21 mixer, JB-28 CPU, JB-30 ARM.

## Source findings
- `Core/Src/Soundengine/DSPAudio/FX/Delay.c` already implements native delay, feedback, tone filtering and ping-pong processing. Do **not** allocate a duplicate large audio delay buffer.
- `Core/Src/Soundengine/FxBus.c` owns the global FX slot and processes the FX bus; delay is selected by `FX_DELAY`. The existing FX buffer is shared with other global FX, so concurrent dub delay + other FX is **not available without architectural changes**.
- `Core/Src/Soundengine/DSPAudio/mixer.c` mixes voice buffers into `fxBusData` and invokes `FxBus_process`. This is the safe insertion point for bounded per-voice *send* taps, not a second delay instance.
- `Core/Src/Soundengine/StepFX.c` is a MIDI retrigger scheduler; no audio delay or send routing exists there.
- Clock source available through `seq_getBpm()` and external sync; use integer bounded subdivisions and clamp time to existing FX buffer limits.

## Atomic implementation
1. Determine FX buffer capacity, sample-rate limits and whether `FX_DELAY` can run as a wet-only auxiliary send while dry voices still route to DAC.
2. Implement `stepfx_dub` control state (enable, send mask, throw gate, feedback 0–90%, rate, safe reset), default OFF and kick excluded.
3. Add mixer tap at the per-voice PCM buffer **before output sum**, scaling with bounded gain and saturating 16-bit additions; never mutate dry voice buffers.
4. Route only through existing `FX_DELAY`; ensure switching off the send stops new input but allows buffered echoes to decay.
5. Implement ramped send-gate changes (minimum 64 samples), wet-only return, prevent feedback > 0.90 and unexpected output clipping.
6. Validate CPU deadline and memory/ITCM in ARM CI; add host test for send-off tail and 2–4 simultaneous voices.
7. Explicitly decide how global FX slot conflict is handled (disable dub sends if other FX selected, or opt-in takeover with restoration). Never silently change user's FX settings.

## Exit criteria
Demonstrated audio path, exact source diffs, no dry bypass changes, no new large buffer, verified delay tails, feedback stability, and independent review before ARM candidate.
