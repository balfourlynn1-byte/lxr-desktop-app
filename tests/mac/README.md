# JIMBONES 1.7.99 • Intel Mac listening bench

Extract JIMBONES-Mac-Test-Bench.zip and double-click JIMBONES.app. The app is unsigned. If macOS blocks a copy you trust, try opening it, then use System Settings → Privacy & Security → Open Anyway. Test execution uses /usr/bin/python3 from Apple Command Line Tools. If prompted, install the tools once and reopen. The audio ZIP plays without development tools.

Click **Run All Tests**, then **View Results**. Each run creates a fresh directory under ~/Library/Application Support/JIMBONES/Results. Open results.json for pass/fail, peak levels, rail counts, PCM hashes and timings. Each WAV is stereo, 16-bit, 44140 Hz and 12 seconds. Compare Erica, NoClip and Combined-off at the same listening level. Compare Metallic, Wavetable, WaveShape, Overlap-1 through Overlap-6 and Layers-plus-StepFX. Listen for a crack on tom/hat changes or on a soft hit following a loud one. Report filename, timestamp, headphones or speakers, and the results.json from the same run. The two Play buttons open bundled renders in your default audio player.

The deterministic MIDI file uses channels 1–7 and the same note-on/velocity timeline as events.txt. Slot numbers in results are one-based. The overlap sweep enables both layers on the first N voices while the whole kit plays. Faders 0.4, seed 123, maximum experimental decay, fixed neutral macro settings except the designated WaveShape pass. The No Clip source is the recovered baseline. Original is upstream a43cd4fc. revision.txt identifies the combined source. The peak adjacent difference is descriptive and can include legitimate percussion attacks. Full-scale sample counts cannot establish the absence of audible distortion.

Mac mean_us and peak_us measure elapsed time for 64-frame calls to the host production renderer, including host scheduling. On the LXR, Performance page 4 displays render load and peak, deadline misses and output samples near a rail. Turn the detail control for a 64-block exponential moving average, pending DMA block count and layer knee activity. DMA counts a still-pending render when the pacing I2S callback next requests a block. It is an indicator, not a DAC underrun measurement. The load readout caps at 255%. No physical timing samples have been collected for this build.

Reproduce on Intel macOS with Git, Apple Command Line Tools, CMake and Ninja installed: bash tests/mac/build.sh /path/to/upstream /path/to/noclip /path/to/packages. For an individual test, run /usr/bin/python3 JIMBONES.app/Contents/Resources/bench.py crunch /tmp/jimbones-results. Do not copy these packages to a firmware update card.
