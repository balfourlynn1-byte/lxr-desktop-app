# JIMBONES 1.8.01 • hardware readiness and recovery

Status: Intel production DSP / peripheral emulation and cross-compiled desktop STM32F765VG application. Physical LXR-02, Performance Pad, KT-10, FD-8, Ableton routing, analogue outputs and device timing remain unverified. Hardware flashing is pending a separate review. This listening release contains no installer for the instrument.

## Gain and compatibility

The native voice buffers, routing accumulators and return path use 16-bit audio; multiple per-voice contributions use saturating addition before FX return. Original-only full-fader playback can already reach a rail. Added voices can increase this. Lowering a finished output cannot repair an earlier saturated sum. Live balance applies fixed control-dependent gain before routing to the output and FX send. Where the squared fader gain exceeds 0.161 the staged value is 0.161 + 0.04 × (fader gain − 0.161). The opt-in non-kick allocation blends toward this curve according to the loudest configured layer level and blend. It never changes the kick relative to legacy staging. There is no guarantee that arbitrary kits, extreme insert drive, FX feedback or an already clipped single voice will have headroom. Tests capture the emulator’s main stereo output. The firmware RAIL meter also scans the other stereo output.

Original kits without an extension default to mode 0. The v1.7.x trailer is migrated from 28 to 32 parameters with neutral defaults; v1.8.00 and .01 share the same checksummed kit trailer. Host fixtures exercise real save/load and autosave paths with legacy, truncated and corrupt input. They cannot validate the physical card or recover overwritten kit data. No Clip retrigger smoothing on the first three drum voices is inherited; the appropriate bypass comparison is recovered No Clip. Stock Erica audio is included separately.

## Timing and device acceptance

Source configuration uses a 16 MHz external clock, PLLM 8 / PLLN 216 / PLLP 2 and AHB divide-by-one, giving a nominal 216 MHz Cortex-M7. The 45.2 MHz I2S source with 256× MCLK and divide-by-four gives 44,140.625 frames/s. A 64-frame double-buffer half is due every 1.450 ms (about 313,181 cycles). The budget is calculated once at startup from SystemCoreClock. DWT CYCCNT measures the Step FX and mixer render interval, including preemption. Each layer has a last-reset peak for its render and staging calls. Wet prefilter injection is included in total workload. Counter scans, comparisons and arithmetic are bounded. The existing callback performs no diagnostic printing, allocation or waits. Mac timings include the host scheduler.

On a separately reviewed unit, reset the CPU page, run the exported live pattern and the fastest intended pad rolls, and photograph current/average/peak, LATE, DMA pending, RAIL and six layer peaks. Record kit, routing, faders, tempo, hat transitions and MIDI path. Compare idle and dense play. Any increment in LATE or the DMA-pending indicator warrants investigation; DMA pending is a missed-service proxy. A CPU percentage alone cannot establish a safe margin. Operating thresholds require measured physical latency, jitter and incident counts.

## Backup and rollback

Before any separately authorised hardware trial, power down, remove the SD card and copy the entire card (including projects, kits, patterns and globals) to a dated folder. Make a second card from that copy and verify its contents. Keep the original card and the working desktop No Clip v1.7.90 image offline. Its SHA-256 is 57ce6e6a6ad729d4e7a4c1d657fce10e39c0c94f94a24abc078442afe74b266c. On Mac, use shasum -a 256 on the file. An SD firmware image backs up the application only. Preserve any unsaved edits through the normal save menu before backing up.

If rollback becomes necessary after an approved trial, use the verified desktop fallback as the only LXR update image in the root of a separate SD card. With the unit off insert the card; hold the encoder while powering on until LXR Updater appears. Keep power connected until Update OK and restart. Remove the updater card and restore the backed-up project card with the unit off. Check kit selection, MIDI mappings, pad response and saved sounds. If the updater reports failure or does not recognise the desktop image, stop and consult Erica Synths support before proceeding. Do not use an LXR Eurorack image. A failed update or damaged bootloader may require service.
